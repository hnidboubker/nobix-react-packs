# @projet-example/sidebar

A customizable React sidebar package. Behavior and state live in the components; layout and styling live in swappable templates. Icon-library agnostic: icons are any `ComponentType<{ className?: string }>`.

Compatible with React 18 and React 19 (peer dependencies).

## Installation

> Placeholder: the package is not published yet.

```bash
npm install @projet-example/sidebar
```

## Templates

| Template   | Description                                                   |
| ---------- | ------------------------------------------------------------- |
| `default`  | Classic sidebar attached to the screen edge.                  |
| `compact`  | Narrower sidebar, suited to dense interfaces.                 |
| `floating` | Sidebar detached from the screen edge.                        |
